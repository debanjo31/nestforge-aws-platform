# NestForge AWS Infrastructure

Terraform for the complete NestForge API platform on AWS. The implementation is split into reusable resource modules and independent `dev` and `prod` roots.

- [Infrastructure operations](infrastructure/README.md)
- [Architecture and decisions](docs/architecture.md)
